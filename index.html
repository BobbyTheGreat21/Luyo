App Introduction

Luyo is an all-in-one clinical workspace designed for Speech-Language Pathologists to facilitate interactive therapy while automating data collection and documentation.

1. Interactive Canvas

The primary workspace allows for real-time visual feedback. Key features include:

  • Ink Pressure: Simulates natural writing weights based on touch pressure.
  • Templates: Cycle through 'Lined Paper', 'Phoneme Maps', and 'Task Strips' using the Layers icon.
  • History Control: Use Undo to revert recent strokes or Clear to reset the board.
  • Color Swatches: Switch between specialized colors for different clinical targets.

2. Clinical Data Logger

Navigate to the List icon to access the quantitative logging suite:

  • Trial Tracking: Tap cards to log Independent, Prompted, Visual Cue, or Incorrect responses.
  • Dynamic Metadata: Assign Goals (e.g., Articulation) and Levels (e.g., Word) to categorize data.
  • Contextual Tags: Apply behavioral tags like "Motivated" or "Fatigued" to add qualitative depth.
  • "+ Other" Button: Add custom goals, levels, or tags on the fly during a session.

3. Session Intelligence

The auto-generating summary at the bottom of the Data pane synthesizes all interactions:

  • Statistical Analysis: Automatically calculates accuracy percentages and independence rates.
  • Prompt Breakdown: Distinguishes between verbal and visual prompt efficiency.
  • Editable Output: You can directly edit the clinical notes; the system will preserve your manual entries while updating the data blocks.

4. Session Management

Global controls located in the top header:

  • Active Timer: Tracks total session duration for billing and focus analysis.
  • Pause/Resume: Toggle the timer for breaks or administrative pauses.
  • Reset: Zero out the session time for back-to-back appointments.
  • Clear All: Located in the Data pane, this wipes all trials and summaries to start fresh.

5. Sound Deck

Located at the bottom of the Canvas view, these high-contrast triggers play crisp phonemic models (S, R, L, TH) to provide consistent auditory targets for the client.
